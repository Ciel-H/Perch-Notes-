# Perch Notes · 栖序便签

Perch Notes（栖序便签）是一款轻量、透明、离线的 Windows 桌面待办工具。它用“类别 → 项目 → 事项”梳理日常计划，可以始终浮在应用上方，也可以安静地沉到其他窗口之后。无需注册账号，内容保存在自己的电脑中。

| 当前版本 | 更新时间 | 支持系统 |
|---|---|---|
| V2.62 | 2026-09-15 | Windows 10/11 x64 |

## 下载与运行

[下载 Perch Notes V2.62 便携版](https://github.com/Ciel-H/Perch-Notes-/releases/download/v2.62/Perch-Notes-v2.62-win-x64.zip)

1. 下载并解压压缩包。
2. 双击 `栖序便签.exe`，无需安装。
3. 如需开机运行，在“设置”中开启“登录 Windows 后自动启动”。
4. 更新前从菜单中完全退出旧版，再用新版程序替换旧文件；已有内容和完成状态会继续保留。

## 产品功能

- **清晰整理**：通过类别、项目和事项组织不同方向的计划，支持展开、折叠和排序。
- **完成管理**：勾选事项后自动显示淡色文字与删除线，并可在“待完成 / 已完成”之间切换。
- **专注模式**：右键事项选择“专注”，即可变成始终置顶的单条任务；点击主页图标返回完整面板。
- **浮沉模式**：“浮”让便签始终位于其他应用上方；“沉”让便签留在普通窗口后方、桌面上方。
- **顶部收起**：点击右上角收起按钮，面板会平滑收向屏幕顶边；移动到顶边即可重新展开。
- **外观调整**：支持跟随系统、暗黑、高级灰和亮白四种外观，并可调节背景透明度。
- **字体选择**：内置 10 款免费中文字体，提供偏小、默认、偏大三档字号，无需额外安装。
- **本地数据**：自动保存、启动快照和每日备份均在本机完成，不依赖账号或网络。
- **安静运行**：主面板不会占用底部任务栏；收起时可通过右下角通知区再次唤出。

## 基本操作

### 新建和编辑

- 点击左侧 `＋` 新建类别，输入框会从加号位置向左平滑展开，并提供 16 种标签颜色。
- 选择类别后，点击顶部 `＋` 新建项目。
- 点击项目右侧 `＋`，在列表中直接新增事项。
- 右键类别或项目可编辑名称；右键事项可进入专注、调整顺序或移入回收站。
- 类别和项目均支持折叠、排序、归档与恢复。

### 显示和收起

- 选择顶部“浮”或“沉”切换窗口层级。
- 拖动标题区域移动面板，拖动右下角调整尺寸。
- 点击右上角向上图标，将面板收至屏幕顶部。
- 面板收起后，通过屏幕顶边窄条或右下角通知区图标重新显示。
- 选择菜单中的“退出”会完全结束程序。

### 设置和数据

- 在右上角菜单中打开设置，可调整外观、透明度、字体、字号和开机启动。
- 数据文件位于 `%LOCALAPPDATA%\Qixu\data.json`。
- 每日备份位于 `%LOCALAPPDATA%\Qixu\backups\`，保留最近 7 份。
- 每次启动还会轮换保留最近 3 份启动快照。
- 更新应用不会创建新的数据结构，也不会覆盖已有事项或完成状态。

## 隐私说明

Perch Notes 不要求登录，不上传待办内容，也不依赖在线服务。所有便签数据由用户自行保存在本机。
