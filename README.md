# Perch Notes · 栖序便签

Perch Notes 是一款轻量、透明、离线的 Windows 桌面待办面板。它用“类别 → 项目 → 事项”整理工作，可浮在所有应用上方，也可沉到其他窗口之后；无需账号，所有内容都保存在本机。

| 当前版本 | 更新时间 | 支持系统 |
|---|---|---|
| V2.55 | 2026-09-14 | Windows 10/11 x64 |

## 下载与运行

[下载 Perch Notes V2.55 便携版](https://github.com/Ciel-H/Perch-Notes-/raw/refs/heads/main/release/Perch-Notes-v2.55-win-x64.zip)

1. 下载并解压压缩包。
2. 双击 `栖序便签.exe`，无需安装。
3. 如需开机运行，在“设置”中开启“登录 Windows 后自动启动”。
4. 更新时退出旧版，再用新版 EXE 替换程序文件；本地事项会继续保留。

## 功能介绍

- **三级整理**：左侧为医院、诊所等类别；类别内建立 APP、HIS 等项目；项目下直接记录事项。
- **完成管理**：事项可勾选完成，完成后文字变淡、增加删除线并自动置底；“待完成 / 已完成”可随时切换。
- **专注任务条**：右键事项选择“专注”，显示只含该事项的置顶任务条；主页图标可返回完整面板。
- **浮沉模式**：“浮”让面板始终位于所有应用上方；“沉”让面板保持在其他应用后方。
- **顶部隐藏**：点击右上角收起按钮或把面板拖到屏幕顶部，即可收成紧贴屏幕顶边的窄条；触碰顶边后点击窄条恢复。
- **外观设置**：支持跟随系统、暗黑、亮白三种外观，透明度实时预览。
- **字体设置**：内置 10 款中文字体，提供偏小、默认、偏大三档字号，无需安装系统字体。
- **项目维护**：支持类别和项目折叠、排序、归档、恢复与回收站。
- **本地保存**：自动保存、每日备份、开机启动、单实例运行，不依赖账号或网络。

## 操作介绍

### 类别、项目与事项

- 点击左侧 `＋` 新建类别。
- 选择一个类别后，点击页面顶部 `＋` 新建该类别下的项目。
- 点击项目右侧 `＋`，直接在列表内新增事项。
- 双击类别、项目或事项名称，可在原位置修改。
- 点击项目右侧 `···`，可置顶、上移、下移、置底或归档。
- 右键事项，可进入专注、调整顺序或删除到回收站。

### 显示与隐藏

- 顶部选择“浮”，面板保持置顶。
- 顶部选择“沉”，面板保持在其他应用后方。
- 点击右上角向上图标，面板会收向屏幕顶部。
- 鼠标移动到面板所在位置的屏幕最顶端，出现窄条后点击即可展开。
- 拖动顶部标题区可移动面板，右下角可调整面板尺寸。

### 设置与数据

- 点击标题旁的 `···` 打开归档、回收站、设置和退出。
- 外观、字体、字号和透明度修改后立即生效。
- 数据文件位于 `%LOCALAPPDATA%\Qixu\data.json`。
- 每日备份位于 `%LOCALAPPDATA%\Qixu\backups\`，保留最近 7 份。
- 点击“退出”会完全结束程序；关闭显示可通过托盘再次唤出。

发布新版只更新程序，不会创建新的业务数据目录或覆盖现有事项。
